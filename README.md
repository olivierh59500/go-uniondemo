# The Union Demo

A native Go/Ebitengine production built with Democonstructionkit (DCK).
The menu connects the individual Union screens while sharing bitmap scrolling,
sprite composition, deformation and YM playback through DCK.

Go 1.26 or newer is required. Dependencies are pinned in `go.mod`, including
YM Player v1.0.0. Artwork and music are embedded in the executable.

The Union's original artists, programmers and musicians retain credit for their
production. This repository contains the native application and its assets.
